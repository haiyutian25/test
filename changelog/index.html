Changelog

Fixes and updates

  1. Mar 23, 2026

    Saved answers and collections

    Your team can now save any Powder response as a verified answer and organize it into collections. Think of it as a living knowledge base that builds itself as your team works. Saved answers stay linked to their original sources, so when the underlying doc updates, Powder flags the answer for review.

    Collections work like shared folders: group answers by topic, client, workflow, or whatever structure your team needs. Pin the most-used collections to your sidebar for one-click access.

    Improved

    • Collections Drag-and-drop reordering within collections
    • Chat Saved answers now surface as suggestions in related conversations
    • Search Full-text search across all saved answers and collections
    • Export Bulk export collections as Markdown or PDF

    Fixed

    • Chat Fixed save button not appearing on streamed responses until page refresh
    • Collections Fixed shared collections not syncing for members added after creation
    • Search Fixed search index not updating after answer edits
  2. Mar 4, 2026

    Source attribution v2

    We rebuilt how Powder cites its answers. Every response now links to the exact paragraph, row, or message it pulled from, not just the document. Click a source badge and you'll jump straight to the highlighted passage in context.

    When multiple sources contribute to an answer, Powder ranks them by relevance and recency. Conflicting information gets flagged automatically so your team can make the call instead of trusting a black box.

    This was our most requested improvement since launch. Attribution is the reason teams trust Powder, so we treated this as foundation work, not a feature.

    New

    • Sources Paragraph-level source linking with highlighted passages
    • Sources Multi-source relevance ranking per response
    • Sources Conflict detection when sources disagree
    • Chat Inline source preview on hover

    Improved

    • Sources Source indexing now 4x faster on large knowledge bases
    • Chat Smoother animations when expanding source cards

    Fixed

    • Sources Fixed rare case where deleted documents still appeared as sources
    • Search Fixed ranking bias toward recently indexed content over relevance
  3. Feb 10, 2026

    Team permissions and roles

    Workspaces now support granular role-based access. Assign members as Admins, Editors, or Viewers to control who can connect sources, trigger actions, and manage billing. Editors can use all features but can't modify workspace settings. Viewers get read-only access to conversations and saved answers.

    For teams handling sensitive data, this means you can onboard new hires into Powder without exposing integration credentials or billing details. Permissions apply instantly and sync across all active sessions.

    New

    • Workspace Role-based access: Admin, Editor, Viewer
    • Workspace Invite links with pre-assigned roles
    • Audit Permission change log for compliance tracking
    • Settings Bulk role assignment for existing members

    Improved

    • Workspace Settings page redesigned for clarity
    • Onboarding New member onboarding flow now shows role-specific feature highlights

    Fixed

    • Workspace Fixed issue where removed members could still access cached conversations
    • Settings Fixed billing page not loading for workspaces with 50+ seats
  4. Jan 20, 2026

    Workspace actions

    Powder can now execute actions directly inside your connected tools. Create a Jira ticket, update a HubSpot deal, send a Slack message, or log a note in Notion, all from the same conversation where you found the answer. No tab switching, no copy-pasting IDs.

    Actions are contextual. When Powder surfaces a support ticket, it already knows the customer, the account owner, and the last touchpoint. Hit "create follow-up" and the fields pre-fill themselves. Every action is logged with full audit trail so your team always knows what happened and who triggered it.

    For launch we're supporting Jira, HubSpot, Slack, Notion, and Linear. More coming based on what teams request.

    New

    • Actions Execute actions in connected tools directly from chat
    • Actions Contextual pre-fill based on conversation history
    • Audit Full action log with timestamps and user attribution
    • Integrations Action support for Jira, HubSpot, Slack, Notion, Linear

    Improved

    • Chat Response streaming now 2x faster on multi-source queries
    • Sources Source cards now show last-updated timestamps

    Fixed

    • Integrations Fixed OAuth refresh loop on long-idle HubSpot connections
    • Chat Fixed edge case where follow-up questions lost thread context
